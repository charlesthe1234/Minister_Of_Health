# Minister of Time

## Overview
Minister of Time is a web application assistant developed by Sing Time Health Tech Pte.Ltd. to help users manage their work and personal life time. The application aims to alleviate stress and promote a balanced life by helping users visualize and rebalance their schedules. It is designed specifically for young Singaporean workers who want to keep their lives well-organized and set clear boundaries between work and personal time.

## Key Features
* **Dual Calendar Management:** Users can manage their time for both work and life. This is visualized through separate work and life dashboards, or a combined calendar overview.
* **Advanced Event Scheduling:** The application supports creating single events. It also includes functionality for batch schedules, such as repeating work shifts, and recurring events.
* **Data Analysis Dashboards:** The dashboards visualize total working and life event times. It includes a breakdown of family time, exercise time, and recreation time using pie and line charts.
* **Stress & Health Analysis:** The system uses algorithms to calculate a user's stress and health levels based on activity satisfaction, sleeping time, and exercising time. It then provides personalized suggestions, such as recommending a hobby if stress levels are too high.
* **Collaborations & Connections:** Users can establish connections with others. This allows them to view shared schedules and send collaborative event invitations.
* **Invite Management (RSVP):** The platform features an inbox system for managing invites. Participants must accept an invitation before being added as a valid participant to an event.
* **Role-Based Event Access:** Event creators can assign roles such as Host, Editor, or Viewer to participants. Only hosts and editors can edit event details, while only hosts can delete events.

## Technology Stack
* **Framework:** Blazor (utilizing .razor components).
* **Database:** Microsoft SQL Server Express.
* **IDE:** Microsoft Visual Studio Community Edition.
* **Version Control:** GitHub.
